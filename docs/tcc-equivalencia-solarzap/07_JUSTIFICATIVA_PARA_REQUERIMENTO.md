# Justificativa para Requerimento

Solicito a analise de equivalencia/convalidacao do Trabalho de Conclusao de Curso com base na possibilidade de apresentacao de documentacao tecnica de desenvolvimento de software acompanhada de relatorio tecnico, conforme previsto no regulamento de TCC da UNIVESP, especialmente no Art. 8º, conforme aplicavel.

O projeto apresentado, denominado **SolarZap**, consiste em uma plataforma web/CRM com automacoes para gestao comercial no setor de energia solar. O sistema contempla desenvolvimento de software, modelagem de dados, autenticacao e controle de acesso, pipeline comercial, gestao de leads e contatos, propostas comerciais, automacoes, integracoes com servicos externos, tracking de conversoes, administracao e documentacao tecnica.

O desenvolvimento do SolarZap ocorreu durante o periodo de integralizacao do curso **[PREENCHER/CONFIRMAR]** e possui relacao direta com a area de Computacao/Ciencia de Dados, por envolver arquitetura de sistemas, banco de dados, automacao de processos, integracao e uso de dados, validacao tecnica e resolucao de problema aplicado.

Dessa forma, solicito que o conjunto documental anexado seja considerado para fins de equivalencia/convalidacao de TCC, ficando a disposicao para apresentar esclarecimentos adicionais, evidencias complementares ou demonstracao do sistema, caso necessario.
