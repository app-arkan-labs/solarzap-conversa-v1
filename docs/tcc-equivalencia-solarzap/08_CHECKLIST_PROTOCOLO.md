## Revisao de confidencialidade

- [ ] Nenhum arquivo `.env` anexado.
- [ ] Nenhum token, secret, chave de API ou bearer token visivel.
- [ ] Nenhum valor de variavel de ambiente incluido.
- [ ] Prints de integracoes sem client secret, webhook secret ou credenciais.
- [ ] Dados de clientes anonimizados.
- [ ] Telefones, e-mails e documentos pessoais ocultados.
- [ ] Dados financeiros/comerciais sensiveis removidos ou ficticios.
- [ ] URLs privadas com credencial ou token removidas.
- [ ] PDFs revisados pagina por pagina.
