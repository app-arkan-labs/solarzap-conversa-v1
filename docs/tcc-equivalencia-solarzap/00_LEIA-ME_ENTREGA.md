# Leia-me da entrega - Dossie TCC SolarZap

## Objetivo desta pasta

Esta pasta contem um dossie tecnico-academico para apoiar a solicitacao de equivalencia/convalidacao de TCC na UNIVESP, com base na documentacao tecnica de desenvolvimento de software do sistema SolarZap acompanhada de relatorio tecnico.

O material foi produzido a partir de inspecao real do repositorio SolarZap, sem alteracao de funcionalidades do sistema e sem exposicao de valores sensiveis. Secrets, chaves, tokens, credenciais e valores de variaveis de ambiente nao foram reproduzidos.
